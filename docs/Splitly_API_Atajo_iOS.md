## Atajos de iOS y Siri

Splitly dispone de una API autenticada que permite registrar gastos directamente desde **Atajos de iOS y Siri**.

El usuario puede generar desde la configuración de Splitly un token revocable que posteriormente utiliza el atajo para:

- seleccionar el grupo;
- introducir el importe;
- indicar el concepto;
- seleccionar la categoría;
- indicar quién realizó el pago;
- decidir cómo dividir el gasto;
- enviar el gasto directamente a Splitly.

Esto permite registrar un gasto sin necesidad de abrir la aplicación web o móvil.

### Descargar Atajo de iOS

**[Añadir Splitly a Atajos de iOS →](https://www.icloud.com/shortcuts/4c7c20d7b672420a8e3f433cef0fd937)**

> En la primera ejecución, el atajo solicitará el token API generado desde la configuración de tu cuenta de Splitly.
